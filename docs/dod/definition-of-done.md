# Definition of Done (utkast)

Ska diskuteras och godkännas av hela teamet i Sprint 0.

En user story är klar när:

- [ ] Alla acceptanskriterier är uppfyllda och demonstrerade.
- [ ] Koden ligger i en egen gren och har gått via PR till `staging`.
- [ ] PR:en är granskad och godkänd av minst en annan person.
- [ ] CI är grönt (lint, typkontroll, bygge).
- [ ] Viktig logik har tester (t.ex. validering och behörighet per roll).
- [ ] Gränssnittet fungerar för alla roller som berörs.
- [ ] Felmeddelanden visas tydligt för användaren.
- [ ] Ingen hemlig information (lösenord, nycklar) finns i koden.
- [ ] Dokumentationen är uppdaterad om något har ändrats.
- [ ] Kortet är flyttat till "Klar" i GitHub Projects.
